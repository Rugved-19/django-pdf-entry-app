# Django PDF Entry App 📄

This is a Django-based web app to:

✅ Add user-specific data entries  
✅ Automatically calculate totals based on decimal chunks  
✅ Generate downloadable PDFs (user-wise or all combined)  
✅ Bootstrap UI with animated user cards and form visuals

---

## 🔧 Features

- Custom user login (non-auth based)
- Entry form with raw input and amount
- Calculates total from decimal split
- Individual + global PDF generation (WeasyPrint + ReportLab)
- Clean Bootstrap frontend
- Delete individual/all entries
